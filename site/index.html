What uv is to pip, for Swift

SwiftPM's own files, several times faster.

swx resolves, builds and runs Swift packages and writes the same Package.resolved, .build/checkouts and workspace-state.json as SwiftPM, byte for byte. Mix swx, swift and Xcode freely; there is nothing to migrate.

curl -fsSL https://jeslyvarghese.github.io/swx/install.sh | sh

macOS 13+ (universal) and Linux (static, x86_64 and aarch64). Or build from source: swift build -c release.

How it is fast

One global store

Blobless bare clones shared by every project. Listing files at any tag is local, and copy-on-write checkouts (APFS clonefile, reflinks) cost almost nothing.

Static manifests

74% of real Package.swift files are read with SwiftParser instead of being compiled and run. Anything that can't be proven harmless is evaluated for real.

Pipelined resolution

A sans-I/O PubGrub solver; while it works, swx lists tags over HTTP (ls-refs), fetches likely manifests and exports checkouts in parallel.

Lockfile fast paths

A matching originHash means nothing to do. Missing checkouts are restored without running the solver.
